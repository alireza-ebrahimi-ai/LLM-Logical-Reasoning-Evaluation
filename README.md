# Do LLMs Really Reason or Just Mimic? A Falsifiable Framework

## Overview
This repository contains the implementation and experimental design for investigating whether Large Language Models (LLMs) genuinely perform formal logical inference or merely reproduce statistical language patterns. The project focuses on First-Order Logic (FOL), specifically testing **Unification** and **Generalized Modus Ponens (GMP)**.

## Objectives and Hypotheses
Contrary to the common assumption that LLMs perform formal logic operations (like variable unification or strict scope tracking of quantifiers), this project proposes a falsifiable experimental framework to test two primary hypotheses:

*   **Hypothesis 1 ($H_1$):** The performance of an LLM drops significantly on logically equivalent inferences when surface-level features are altered (e.g., replacing meaningful constants with nonsensical symbols to eliminate the effect of prior training knowledge, or changing the order of premises).
*   **Hypothesis 2 ($H_2$):** The model systematically fails to distinguish between formulations with swapped quantifiers (i.e., $\forall x \exists y$ versus $\exists y \forall x$) when the surface structure remains nearly identical.

## Repository Structure
*   `/notebooks`: Contains the main Kaggle notebooks used for data generation, model API interaction, and evaluation.
*   `/data`: Contains the generated falsifiable benchmark datasets (Control group, $H_1$ test group, $H_2$ test group).
*   `/results`: Statistical analysis and error categorization (Statistical-Linguistic Errors vs. Genuine Logical Errors).
*   `/docs`: Final report and documentation.

## Evaluation Methodology
This project moves beyond simple "accuracy percentages." We implement:
1.  **Strict Control Groups:** Clean benchmarks that entirely isolate the model's prior educational knowledge.
2.  **Statistical Significance:** Meaningful sample sizes to differentiate between "random errors" and "systematic/structural errors."
3.  **Interpretability:** Error analysis identifying *why* the model failed based on underlying architectural constraints.
